# Kavir's School Admission Form

A simple school admission form created using **HTML and CSS**. This project allows students to enter basic information and select their preferences through an easy-to-use form.

## Features

* Student name, age, and class fields
* Gender selection using radio buttons
* Hobby selection using checkboxes
* Parent's name and email fields
* Submit Application button
* Clean and simple design

## Technologies Used

* **HTML** – Used to create the structure and admission form.
* **CSS** – Used to style the webpage and make it look clean and formal.

## Form Sections

### Student Information

Users can enter:

* Student's name
* Student's age
* Student's class

### Gender

Users can select:

* Male
* Female

### Hobbies

Users can select multiple hobbies:

* Football
* Cricket
* Table Tennis
* Chess

### Parent's Information

Users can enter:

* Parent's name
* Email address
